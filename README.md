## About Me

- Computer Science student at Carleton University building interactive software across AI, algorithms, and music education.
- Built **Tempo** for the OpenAI WebMCP Challenge, exploring how browser-based agents can use the same tools, state, and guardrails as a human-facing application.
- Currently developing **Yuei.AI**, a practical music-reading and ear-training platform, alongside **SearchLabs**, an interactive search-algorithm visualizer.
